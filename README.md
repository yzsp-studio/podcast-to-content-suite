## 🇬🇧 English

Turns one timestamped podcast transcript into a complete content-marketing suite. It first analyses the transcript for themes and subtopics, 5–7 key insights, quotable lines, data and statistics, guest credentials, target audience and actionable advice, preserving the original timestamps verbatim. It then produces an SEO-optimised blog post (1,200–2,000 words with a primary-keyword H1, meta description, H2/H3 structure, embedded quotes and a CTA), social content for Twitter/X, LinkedIn, Instagram and Facebook, an email newsletter, SEO-ready show notes, 3–5 audiogram scripts, and SEO elements covering primary and secondary keywords, meta tags, JSON-LD schema markup and suggested internal links. Finally it assembles a master index from the built-in output template, linking and summarising all six files. Each artifact is written as its own markdown file and registered to the workspace file panel; audiograms are delivered as scripts only — transcript excerpt, timestamps and on-screen text — with no audio or video rendering.

### ✨ What it does

- Transcript analysis: themes and subtopics, 5–7 key insights, quotable lines, data, guest credentials and verbatim timestamps
- SEO blog post: 1,200–2,000 words with a primary-keyword H1, meta description, H2/H3 structure and CTA
- Four-platform social content, one set each for Twitter/X, LinkedIn, Instagram and Facebook
- Email newsletter plus SEO-ready show notes that keep the original timestamps verbatim rather than inventing times
- 3–5 audiogram scripts built from transcript excerpts, timestamps and on-screen text
- SEO elements: primary and secondary keywords, meta tags, JSON-LD schema markup and suggested internal links
